# Event and API contracts

Shared published language for CampusHub.

- `events/` — CloudEvents JSON schemas (`edu.*.v1`)
- `csharp/` — NuGet `CampusHub.Contracts` (Phase 1+)
- `ts/` — npm `@campushub/contracts` (Phase 1+)

Rules: additive changes only; breaking changes ship as a new version suffix.
